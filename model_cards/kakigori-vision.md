# kakigori-vision — music notation detector

Glyph and structure detector for the [kakigori](https://github.com/vibetuned/kakigori)
optical music recognition (OMR) pipeline. Detects **109 classes** of music
notation elements on full score pages — from noteheads, stems, flags, beams,
accidentals and dynamics up to layout structure (systems, staves, measures) —
as the first stage of an end-to-end image → Humdrum `**kern` pipeline.

## Architecture

- **Backbone**: ConvNeXt-Base pretrained with DINOv3
  (`timm/convnext_base.dinov3_lvd1689m`)
- **Neck**: PANet feature pyramid over three backbone stages
- **Heads**: CenterNet-style heatmap + size regression, one channel per
  class, focal loss with progressive gamma
- **Input**: 640×640 letterboxed page images (grey padding, value 114)

## Training

Trained on ~9k rendered score pages (Verovio renders of a curated MusicXML
corpus) plus ~15k synthetic pages generated by mutation of the corpus
(rare-class oversampling: octave clefs, uncommon dynamics, time signatures,
double barlines, clef changes). Recipe: base run from scratch → synthetic
fine-tune → consolidation at 9:1 real:synthetic, then a class-expansion
retrain (107 → 109 classes, two-stage freeze schedule) and two octave-clef
consolidation rounds.

## Evaluation

On held-out rendered pages (unseen scores, same engraving process):

| set | mAP@.50 | mAP@.50:.95 |
| --- | --- | --- |
| validation-small (325 pages) | 0.724 | 0.644 |
| validation-test (hard mixed forms) | 0.741 | 0.660 |
| test-small (484 unseen pages) | 0.722 | 0.637 |

Strong classes sit at 0.95–1.00 AP (clefs, noteheads, key accidentals,
common dynamics). Known weak groups:

- **Thin/small glyphs** (`beamBroken`, `stem32`, `ledgerLines`, `meterSig`,
  digit time signatures): frequent but low AP — limited by the 640 px input
  resolution, not by data.
- **`clefG8va`** (AP ≈ 0.32): localization is perfect but the ~3 px "8"
  above the clef is below the input's resolving power, so classification
  votes split toward `clefG`/`clefG8vb` (AP 0.96).

## Usage

```bash
# weights -> checkpoints/release/vision/model.safetensors
uv run infer-model --checkpoint checkpoints/release/vision \
                   --pdf score.pdf --output-dir out/
# outputs page_NNNN.png + page_NNNN.json (class/score/bbox per detection)
```

Trained and evaluated on digitally rendered pages; scanned/photographed
scores are out of the training distribution (a scanner-style augmentation
pipeline is used in training, but no real scans were seen).

Part of the kakigori OMR project — see the
[full-pipeline model](https://huggingface.co/vibetuned/kakigori-omr) that
consumes these detections. License: AGPL-3.0-only (note: the DINOv3
backbone weights carry their own upstream license).
